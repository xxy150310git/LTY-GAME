# 洛天依接歌词 · 锦依卫特训

一个纯前端的洛天依歌词小游戏合集。零框架、零依赖、零后端，进入xiaobaixxy.cc.cd/LTY-GAME 就能玩。

题库收录 **23 首歌、500 道题**，玩法有 **接歌词 / 猜歌名 / 记忆翻牌** 三种。

---

## 快速开始

```
进入xiaobaixxy.cc.cd/LTY-GAME
```


---

## 三种玩法

在开始页的「玩法」里切换。

### 1. 接歌词

给出某首歌的一句上半句，从四个选项里选出下半句。

- 答对：选项变绿、显示「✓ 接上了！」，**+10 分**，1.2 秒后自动下一题
- 答错：你选的那条变红、正确的那条同时标绿、其余淡出，方便对照

### 2. 猜歌名

给出**一句歌词**（随机取上半句或下半句，避免背题），从四个歌名里猜是哪首歌。

- 题干上方会**藏起歌名标签**，否则答案直接露馅
- 干扰项从全部 23 首歌里抽
- 答对显示「✓ 猜对了！」，答错显示「✗ 这首歌是：《歌名》」
- **至少要勾 2 首歌**才能开始，只勾一首的话每题答案都是它

### 3. 记忆翻牌

经典的 4 × 4 配对玩法，**8 对共 16 张牌**。

- **牌面上是一句歌词**，每首歌取**两句不同的词**各做一张牌
- **两张牌出自同一首歌就算配对成功**（两张的词长得不一样）
- 翻第二张才计一步；配对了弹一下再消除，配错了亮一会儿再扣回去
- 左上角计时、右上角步数、中间显示已配对数
- 全部配对完 → 停表 → 弹出庆祝面板 + 撒花

> 牌面**不放这首歌的专属插画**。因为每首歌有唯一插画，留在牌面上同歌两张牌图案就一样了，配对会变成"找相同图案"、根本不用看词。所以牌面只用统一的装饰图 + 加深的天依蓝，认的是词不是图。

**每轮题数**可自由选择：

| 玩法 | 可选题数 |
|---|---|
| 接歌词 | 5 / 10 / 20 / 50 |
| 猜歌名 | 5 / 10 / 20 |
| 记忆翻牌 | 固定 8 对（不显示这一栏）  |

在接歌词选了 50 题、再切到猜歌名时，因为 50 不被支持，会自动回落到 10 题。

## 歌曲库

开始页点「歌曲库」打开弹窗。

- 顶部写着「本网站已收录 23 首歌曲」
- 有一个 ☑ **全部选择 / 全部取消选择**复选框，部分选中时显示半选状态
- 每行一首歌：勾选框 + 《歌名》 + 题数
- 底部是 **导出 PDF** 和 完成

勾选结果会实时反映在入口按钮上，比如：

| 状态 | 入口显示 |
|---|---|
| 全选 | 已选 23 / 23 首 · 共 500 题 |
| 只勾 12 首 | 已选 12 / 23 首 · 共 268 题 |
| 记忆翻牌 · 全选 | 已选 23 / 23 首 · 4 × 4 共 8 对 |
| 记忆翻牌 · 只勾 7 首 | 记忆翻牌至少要选 8 首歌哦（要凑 8 对） |

**三种玩法共用同一份勾选**。

限制条件：

- **接歌词 / 猜歌名**：至少要勾 1 首（猜歌名要 2 首）
- **记忆翻牌**：至少要勾 8 首，因为 8 对需要 8 首**不同的**歌（一局里同一首歌只出现一对）

不满足条件时入口那行会变红提示，开始按钮也会锁住。

### 导出 PDF

点弹窗底部的「导出 PDF」：

- 把**当前勾选的歌曲**排成一份卷子（题干 + A/B/C/D 四个选项）
- 末尾单独放一节答案
- 然后唤起浏览器的打印窗口，选「另存为 PDF」

导出内容**跟着当前玩法走**——猜歌名模式下导出的就是"歌词 + 四个歌名选项"。

> 用的是浏览器自带的打印功能。纯前端要直接生成带中文的 PDF 得内嵌字体，不现实，打印是最稳的做法。

长卷子导出页数较多（500 题会很长），建议只勾几首再导。

## 复习依下

开始页的「复习依下」按钮，打开就能看**已勾选那几首歌的完整歌词**。

- 每首歌一块：该歌的专属插画 + 《歌名》 + 全部歌词
- 一句话都不少——题库里每条存的是「相连的两句」且相邻两条会重叠一句，歌词单会把两句都按顺序铺开、重复的只算一次，所以拼出来是完整的一整首
- **勾超过 6 首时**，顶部会出现一排可横向滑动的歌名胶囊，点一下滚到那首歌并高亮
- 一首歌都没勾时按钮会灰掉

> 点击「开始特训」会自动关闭歌词单。

## 计分与评价

答对一题 10 分。结算页显示总分、正确率、答对题数，还会给一句评价：

| 正确率 | 评价 |
|---|---|
| ≥ 95% | 锦依卫指挥使！歌词已经刻进 DNA 里啦。 |
| ≥ 85% | 锦依卫千户，实力相当能打。 |
| ≥ 70% | 锦依卫百户，再练练就更稳了。 |
| ≥ 50% | 锦依卫小旗，底子有了，多听几遍歌吧。 |
| ≥ 25% | 刚入门的小锦依卫，去把这几首歌循环一下～ |
| < 25% | 别灰心，先去听一遍《蝴蝶》再来！ |

记忆翻牌按步数评价（≤12 / ≤20 / ≤30 / 更多），并显示用时。

> 每题只有一次作答机会，答错即显示原句并跳下一题；正确率按这个口径算。

## 题库格式

在 `app.js` 顶部的 `QUESTIONS` 数组里，每道题就是一个对象：

```js
{ song: "蝴蝶", q: "走吧 就算我们无法让大雨停下", a: "还有我 陪你在雨里放肆奔跑啊" }
```

- `song`：歌曲名
- `q`：上半句
- `a`：下半句（也就是玩家要选出来的那一句）

**`a` 必须紧跟 `q`**——它们是歌词里相连的两句，因为「接歌词」玩的就是"接下一句"。

**相邻两条会重叠一句**：第 N 条的 `a` 常常就是第 N+1 条的 `q`。歌词单（复习依下）就是靠这个重叠关系把整首词拼回来的，所以写题库时保持这个衔接习惯，歌词单才会连贯。

### 加歌 / 加题

只需要往 `QUESTIONS` 里追加对象，**其他都不用动**：

- 歌曲库列表、题数、勾选框会自动出现
- 歌词单会自动多出这首歌
- 记忆翻牌的牌面会自动用上

有**一处需要手动补**：如果是一首全新的歌，去 `SONG_ART` 里加一条插画，否则「复习依下」里这首歌会走兜底图案。

```js
"歌名": { bg: "linear-gradient(140deg,#8ad9ff,#3aa2dd)",
        art: '<path d="..."/>' },
```

`art` 是 SVG 路径片段（`viewBox` 是 24×24，`stroke` 用 `currentColor`），`bg` 是那块小图的背景渐变。**每首歌的插画最好不一样**——不是为了翻牌（牌面已经不用它了），而是歌词单里一眼能认出是哪首。

## 可调参数

都在 `app.js` 顶部，想改手感直接调这几个常量：

| 常量 | 默认 | 作用 |
|---|---|---|
| `SCORE_PER_QUESTION` | `10` | 每题分值 |
| `OPTION_COUNT` | `4` | 每道题几个选项 |
| `DELAY_CORRECT` | `1200` | 答对后停留毫秒数 |
| `DELAY_WRONG` | `2200` | 答错后停留毫秒数（长一些，方便看清原句） |
| `MEMORY_PAIRS` | `8` | 翻牌对数，改它就能扩成 6 × 6（需要 18 首歌） |
| `MEMORY_FLIP_BACK` | `1300` | 翻错后扣回牌面的毫秒数 |
| `REVIEW_JUMP_MIN` | `6` | 勾选超过几首时歌词单出现跳转条 |
| `MODES` | — | 三种玩法的名称、说明、可选题数 |

改 `MEMORY_PAIRS` 扩成 6 × 6 时，还要同步改 CSS：把 `.mem-board` 的
`grid-template-columns: repeat(4, minmax(0, 1fr))` 改成 `repeat(6, ...)`，
并把 `.mem-lyric` 的字号调小一档（格子变小，歌词会挤）。

## 判分规则

「接歌词」用输入框判分的容错逻辑保留在代码里（`isCorrect()`），当前四选一模式下用于**判断两个选项是否等价**，避免出现"选哪个都对"的选项。容错从宽到严共六层：

1. 归一化后完全相同（忽略空格、全半角、中英文标点差异）
2. 去掉英文尾缀后相同（`NaYo`、`Ayo` 这种不写也算对）
3. 互为子串且长度接近（比值 ≥ 0.7）
4. 长度差太多直接判错（比值 < 0.55）
5. 编辑距离相似度 ≥ 0.82（放过错一两个字）
6. 相邻两字词组覆盖率 ≥ 0.9（核心词对得上）

## 已知限制

- **没有存档**：不写 `localStorage`，刷新后勾选和成绩都会重置
- **导出 PDF 依赖浏览器打印**：需要用户在打印窗口里手动选「另存为 PDF」
- **歌词为公开资料整理**：来自萌娘百科 / 百度百科 / VCPedia 等处的公开歌词，仅供学习交流
- **《九九八十一》等几首的歌词单顺序可能跳段**：因为当初出题时不是严格按全曲顺序铺的，句子是全的但次序会有跳跃

## 浏览器要求

需要支持 CSS 3D 变换（翻牌）、`grid`、`aspect-ratio`、`-webkit-line-clamp` 的现代浏览器：

Chrome / Edge 90+、Firefox 89+、Safari 15+

（`backdrop-filter` 毛玻璃在旧版 Firefox 上会退化成不模糊，不影响功能。）

手机可直接玩，窄屏布局按 360px 视口验证过。
